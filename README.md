# QVYX 3D Studio — многостраничный сайт

Статический сайт на HTML, CSS и JavaScript. Все страницы используют общий стиль `site.css`, меню и небольшой скрипт из `site.js`, а также фирменный логотип `assets/qvyx-logo.png`.

## Страницы

- `index.html` — главная: первый экран, услуги, блок печати STL и контакты внизу.
- `cases.html` — кейсы Dushanbe City, Alif Bank, кофейни, автосервисы, дрон и Cashservice.tj.
- `products.html` — NFC-брелоки, детали по STL/чертежам, рельефные карты и кастомный мерч.
- `nfc.html` — лёгкая визитка для NFC-метки, только контакты и кнопка на сайт.
- `card.html` — копия NFC-визитки, если удобнее использовать такой URL для NFC-метки.

## Как открыть

Распакуйте папку целиком и откройте `index.html` в браузере. Не перемещайте HTML-файлы отдельно от `site.css`, `site.js` и папки `assets` — они нужны для корректного оформления и логотипа. Для публикации загрузите все файлы и папку `assets` в корень сайта на хостинге.

## Перед публикацией — замените контакты

Пока что в коде стоят явные заполнители, потому что реальные телефоны, Telegram, WhatsApp и email не были предоставлены.

В `index.html` замените значения рядом с комментариями:

- `<!-- contact1: telegram -->` — ссылка `https://t.me/YOUR_TELEGRAM`.
- `<!-- contact2: whatsapp -->` — номер в ссылке `https://wa.me/992XXXXXXXXX`, цифры с кодом страны без знака `+`.
- `<!-- contact3: phone -->` — ссылка `tel:+992XXXXXXXXX` и текст номера.
- `<!-- contact4: address -->` — адрес, если формулировка должна быть другой.
- `<!-- contact5: email -->` — `mailto:YOUR_EMAIL@example.com` и видимый адрес почты.

Те же три ссылки надо заменить и в `nfc.html` (или `card.html`), рядом с комментариями `<!-- contact_tg -->`, `<!-- contact_wa -->` и `<!-- contact_phone -->`.

## Как добавить свои фотографии

Положите фото в `assets/`, затем замените placeholder-блок на изображение внутри соответствующей обёртки. Например, в `cases.html` замените содержимое блока с комментарием `<!-- photo1: case_alif -->` на:

```html
<img src="assets/case-alif.jpg" alt="Корпуса камер для банкоматов Alif Bank">
```

Сохраните внешний элемент с классом `case-photo media-placeholder` или поменяйте его на `class="case-photo"`. CSS автоматически растянет фотографию по блоку с `object-fit: cover`.

Маркеры фотографий в `cases.html`: `<!-- photo1: case_alif -->`, `<!-- photo2: case_dc -->`, `<!-- photo3: case_other -->` (и дополнительные маркеры для других кейсов). В `products.html` есть `<!-- photo_product1 -->` и далее до `<!-- photo_product4 -->`.

## Заметки

Шрифт Jost загружается с Google Fonts при наличии подключения к интернету; при его отсутствии применяется Arial. Форма отправки не подключена к серверу, а реальные контактные ссылки нужно указать перед публикацией. Декоративные блоки на местах фотографий — это заглушки, а не готовые изображения.
